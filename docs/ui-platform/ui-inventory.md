# UI Inventory

This inventory records the UI files present in the repository during the UI platform audit. It is limited to file-level facts and does not change runtime behavior.

## Entry Points

- `UI/main.py`: active Python launcher for the Qt Quick UI. It creates the `QGuiApplication`, configures `QQmlApplicationEngine`, adds `UI/CustomComponents` as a QML import path, creates the `UIManager` model, exposes it as the `myModel` root context property, and loads `UI/qml/App.qml`.

## Root QML

- `UI/qml/App.qml`: top-level `Window` using Qt Quick 6.5. It hosts `Main`.
- `UI/qml/Main.qml`: main application layout using Qt Quick 6.5 and Qt Quick Controls 6.5. It binds the root context `myModel` to a `UIManager` property and composes the main screens.

## Active QML Screens

- `UI/qml/APIPointScreen.qml`: point API panel placeholder bound to `APIPointModel`.
- `UI/qml/APIRangeScreen.qml`: range API panel for choosing dimensions.
- `UI/qml/APIScreen.qml`: API selector panel and API-specific sub-screen host.
- `UI/qml/FunctionScreen.qml`: statistic/function selection panel.
- `UI/qml/MathObjectScreen.qml`: command/math object selection panel.
- `UI/qml/ParameterScreen.qml`: command parameter panel keyed by the selected math object.
- `UI/qml/RestrictionGroup.qml`: restriction group editor loaded dynamically by the restriction screen.
- `UI/qml/RestrictionScreen.qml`: restriction group list and add-group control.

## Python QML-Exposed Models and Helpers

- `UI/qml/APIModel.py`: base API description model exposed with `QmlElement`.
- `UI/qml/APIPointModel.py`: point API model subclass.
- `UI/qml/APIRangeModel.py`: range API model with dimension options and chosen dimensions.
- `UI/qml/APIScreenModel.py`: API list, selected API key, and API model map.
- `UI/qml/FunctionScreenModel.py`: function/statistic choices and selected choice.
- `UI/qml/MathObjectScreenModel.py`: command/math object choices and selected choice.
- `UI/qml/ParameterScreenModel.py`: parameter map keyed by command.
- `UI/qml/RestrictionGroupModel.py`: selected restriction parameter sets for one group.
- `UI/qml/RestrictionScreenModel.py`: available restrictions, restriction parameter templates, and mutable restriction groups.
- `UI/qml/UIManager.py`: aggregate view model and command/query coordinator.
- `UI/CustomComponents/python/NameDescModel.py`: reusable name/description/key/selection model.
- `UI/CustomComponents/python/ParameterModel.py`: reusable parameter model with value, type, and required flag.
- `UI/CustomComponents/python/ParameterSetModel.py`: reusable descriptor plus parameter-list model.
- `UI/CustomComponents/python/importer.py`: empty helper/module placeholder present in the custom component Python package.

## Custom QML Templates

- `UI/CustomComponents/templates/BooleanParameter.qml`: boolean parameter row with a checkbox and binding back to `ParameterModel.value`.
- `UI/CustomComponents/templates/ClickAndScroll.qml`: selectable scrolling list wrapper.
- `UI/CustomComponents/templates/ColumnLoader.qml`: dynamic column loader for model-backed delegates and callback wiring.
- `UI/CustomComponents/templates/Constants.qml`: singleton constants for dimensions, colors, and fonts.
- `UI/CustomComponents/templates/ListPick.qml`: reusable selectable list with a header and selected-choice label.
- `UI/CustomComponents/templates/NameDesc.qml`: reusable name/description display row.
- `UI/CustomComponents/templates/NameDescClick.qml`: clickable name/description row with selected state.
- `UI/CustomComponents/templates/NameDescDel.qml`: name/description row with delete action.
- `UI/CustomComponents/templates/ParameterScroll.qml`: dynamic parameter-list scroller choosing string or boolean parameter delegates.
- `UI/CustomComponents/templates/ParameterSet.qml`: restriction parameter-set display and edit dialog.
- `UI/CustomComponents/templates/ScrollLoader.qml`: scroll view wrapper around `ColumnLoader`.
- `UI/CustomComponents/templates/StringParameter.qml`: string parameter row with a text field and binding back to `ParameterModel.value`.
- `UI/CustomComponents/templates/qmldir`: QML module directory file for the `templates` import.

## Generated and Resource Files

- `UI/style.qrc`: Qt resource manifest. It includes `qtquickcontrols2.conf`.
- `UI/style_rc.py`: generated Python resource module from Qt resource tooling. Its header identifies resource object code generated by the Qt Resource Compiler for Qt 6.7.1, and the file should not be hand-edited.
- `UI/qtquickcontrols2.conf`: Qt Quick Controls style configuration referenced by the resource manifest.

## Legacy, Sample, or Unclear Artifacts

- `UI/view.qml`: older or sample-style QML artifact. It imports QtQuick 2.0, QtQuick.Layouts 1.11, QtQuick.Controls 2.1, QtQuick.Window 2.1, QtQuick.Controls.Material 2.1, and `io.qt.textproperties 1.0`; it is not loaded by `UI/main.py`.

## Qt Designer Artifacts

No `.ui` Qt Designer files were found in the inspected search. The inspected Designer-related search found only `UI/style.qrc`, which is a Qt resource manifest rather than a Designer form.
